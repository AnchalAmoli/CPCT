# CPCT

Cancer Patient Care Tracker

A simple Python program designed to help hospital staff manage cancer patient records, assign doctors, log vitals, and track treatment schedules.

## Project Structure

The project is organized into four main files:

- module 1: Defines the basic classes (`Patient`, `Doctor`, and `Treatment`) along with validation rules.
- module 2: Contains the Tracker System class that manages all patient and doctor records, assignments, and logs.
- module 3: Provides the user menu interface and runs the application.
- `statement.md`: Project summary explaining the problem, scope, and key features.

## How to Run

1. Open your terminal or command prompt.
2. Navigate to the project folder:

   ```bash
   cd cancer_care_tracker
   ```
